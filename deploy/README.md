# Deploy Motor World on the web

**Open this file and follow it in order:**

### [STEP_BY_STEP_WEB.md](./STEP_BY_STEP_WEB.md)

That guide uses **one API server (Render) + one static site (Vercel) + your own domain**.  
You only copy **two** main secrets-style variables: **`MOTOR_WORLD_APP_SECRET`** and **`MOTOR_WORLD_ORIGINS`** (plus your API URL on Vercel as `VITE_API_BASE_URL`).

The older technical notes live in `docs/SETUP_FROM_ZERO.md` (short pointer) and `server/README.md`.
